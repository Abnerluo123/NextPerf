# 为什么"锁帧 + 垂直同步"才是流畅的关键

> 这篇是给**玩家**看的（不是给改代码的人看的）。所有数字都是本项目在真实游戏上的实测，
> 不是理论推算 —— 你可以在自己的机器上用 NextPerf 的面板复现。

## 一句话结论

**显示器每 1/60 秒才有一次"上屏"机会。游戏一秒画 105 张，显示器一秒只能收 60 张 ——
多出来的那些要么被丢掉、要么在屏幕扫到一半时被换掉（撕裂）。眼睛看到的是"不均匀"，
于是：平均帧率更高，体感反而更差。**

## 实测对照（《漫威蜘蛛侠》，同一台机器、同一场景）

| 设置 | 面板 `帧率 / 帧时间` | `1% Low` | 眼睛的感觉 |
| --- | --- | --- | --- |
| **锁帧 + 垂直同步** | 60.0 fps / **16.6~16.7 ms（几乎不动）** | ≈ 59 | 顺 |
| **关垂直同步 + 不锁帧** | ≈ 105 fps / 平均 9.5 ms（**更"快"**） | 屏幕 60Hz → 真正上屏的只有约 60 帧/秒 | **卡、撕裂** |

关键点：**流畅与否取决于"帧到达眼睛的时间是否均匀"，而不是每秒画了多少张。**

## 三个概念，用显示器/游戏的语言说

1. **显示器刷新率**：60Hz = 每 **16.67 ms** 一次上屏机会。屏幕不会"半路"上屏 ——
   这一周期没用掉的机会就浪费了。
2. **垂直同步（VSync）**：让游戏提交的帧**等到下一次刷新机会**再上屏。
   于是每一帧在屏幕上停留**整数个**刷新周期（16.67 ms、33.3 ms、50 ms…），
   时间间隔整齐 → 顺。
   - 代价：多等一点 → 输入延迟略高；某一帧没画完就会掉到 33.3 ms（这就是"掉帧"）。
3. **锁帧（帧率上限）**：让游戏的产出速度**不超过**刷新率（60Hz 锁 60，或锁 58~59）。
   这样每帧都能安稳等到自己的刷新机会，不会出现"两张挤进一个刷新周期、下一个周期空着"
   的节奏抖动。
   - 为什么常有人推荐"锁 59 而不是 60"：略低于刷新率能让每帧都**提前一点**到达，
     避开"刚好压在边界上"的抖动。最佳值因引擎/驱动而异，**试出来最顺的那个**。
4. **不锁帧 + 关同步**：一秒产出 105 张，却只有 60 次上屏机会 →
   一部分帧在扫描中途被替换（**撕裂**）、一部分被直接丢弃 →
   上屏节奏不再均匀 → **平均 FPS 更高、体感更差**。

## 那 G-Sync / FreeSync（可变刷新率）呢

它们让**显示器跟着游戏走**：游戏出帧慢，屏幕就刷得慢。于是既不需要等固定周期，
也没有撕裂与节奏抖动 —— 这是目前最理想的方式。

⚠ 但仍要**锁帧到刷新率上限以下**（常见做法：刷新率 −3 左右）：一旦超过上限，
就又回到"上屏机会不够"的老问题。

## 用 NextPerf 面板怎么判断自己顺不顺

| 面板行 | 怎么读 |
| --- | --- |
| `帧率 / 帧时间` | 锁帧 + 同步时它应该**几乎不动**（例如一直 16.6~16.7 ms）。数值一路跳 = 节奏不稳 |
| `1% Low` / `0.1% Low` | 最差那 1% / 0.1% 的帧有多慢。**它对"卡不卡"的敏感度远高于平均帧率** |
| 口诀 | **平均高但 Low 低 = 节奏不稳；两者都高且接近 = 真的顺** |

## 实用建议（按优先级）

1. **有 G-Sync / FreeSync**：打开它 + 锁帧到刷新率以下。
2. **没有 VRR**：开垂直同步 + 锁帧到刷新率（或略低）。**宁可 60 稳，不要 105 抖。**
3. **竞技类要最低延迟**：关同步 + 不锁帧确实延迟最低 —— 但那是"拿流畅度换延迟"的取舍，
   看一眼 `1% Low` 就知道自己付了多少代价。
4. 改完设置**让面板和眼睛互相印证**：`帧时间` 是否稳定、`1% Low` 是否接近平均值。

## 关于我们的数字（诚实说明）

- 面板现在的 `帧率 / 帧时间 / 1% Low` 在**管理员运行**时取自驱动的显示事件（ETW），
  垂直同步下与显示器实际节奏一致（约 16.67 ms 一步）。
- "关同步 + 不锁帧"时我们给的是**应用提交的帧率**（PresentMon 里叫 *Presented FPS*）：
  105 fps 表示游戏确实画了 105 张；而**屏幕真正显示了多少张**（*Displayed FPS*）
  是另一个数，本项目**还没接**（见 `docs/TODO.md` 的 F4）。这也是为什么那种设置下
  你会觉得"数字更快、但看着更卡" —— 两个数说的是两件事。
