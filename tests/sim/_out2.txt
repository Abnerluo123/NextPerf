NextPerf 模拟游戏进程（DX11 / DX12 双后端）

用法: sim.exe [--api=dx11|dx12] [--seconds=N | --frames=N] [选项...]

流程控制
  --api=dx11|dx12        图形后端（默认 dx11）
  --seconds=N            跑 N 秒后正常退出（默认不限时）
  --frames=N             跑 N 帧后正常退出（与 --seconds 互斥）
  --warmup=N             前 N 帧不计入统计（默认 10，剔除首帧编译抖动）
  --no-stdin             不读 stdin 控制命令

帧率与显示
  --fps-cap=N            锁帧到 N fps，0=不锁（默认 0）
  --vsync=on|off         垂直同步（默认 on）
  --width=W --height=H   初始分辨率（默认 1280x720）
  --buffers=N            交换链 buffer 数 2..4（DX11 默认 2，DX12 默认 3）
  --window-mode=MODE     windowed | borderless | fullscreen（默认 windowed）
  --hidden               不显示窗口（无头 / CI 跑）
  --hold-ms=N            每帧在 CPU 侧额外占用 N 毫秒（模拟逻辑开销）
  --gpu-load-ms=X        每帧追加约 X 毫秒的 GPU 工作量（模拟 GPU 压力）
  --no-tint              背景色不再逐帧变化（对照实验用）

输出
  --json                 每帧输出一行 JSON 到 stdout（诊断信息一律走 stderr）
  --json-every=N         每 N 帧输出一行（默认 1）
  --list-outputs         列出显示输出后就退出
  --help                 显示本帮助

运行时控制（stdin 逐行命令，详见 tests/sim/README.md）
  resize W H             改分辨率（触发 ResizeBuffers）
  window MODE            切窗口状态 windowed|borderless|fullscreen
  vsync on|off           开关垂直同步
  fpscap N               改锁帧值（0=不锁）
  holdms N               改每帧 CPU 侧开销
  gpuload X              改每帧 GPU 侧负载（毫秒）
  stats                  立即输出一份汇总 JSON
  status                 输出一行当前状态 JSON
  mark NAME              在输出里插一条标记（对齐脚本时间轴）
  quit                   正常退出（会输出汇总 JSON）
